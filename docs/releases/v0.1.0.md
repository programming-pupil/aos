# AOS v0.1.0

AOS 的首个开源版本，面向团队级 Agent 工作、深度研究、超级对抗、数据探索与工程方案设计。

The first open-source AOS release for team Agent workflows, deep research, super adversarial analysis, data exploration, and engineering plan design.

## 主要能力 / Highlights

- 超级助手：会话、Skill、MCP、内置与增强联网检索。
- 深度研究、超级对抗与数据归因工作流。
- NL2SQL 数据探索及 MySQL、PostgreSQL、MongoDB 等数据源接入。
- Bot 网关及飞书、钉钉等协作平台集成。
- 渐进式工程方案设计与代码仓库上下文。
- SQLite 平台存储、租户隔离、权限与审计能力。

- Super Assistant with sessions, Skills, MCP, and built-in or enhanced web search.
- Deep research, super adversarial analysis, and data attribution workflows.
- NL2SQL exploration with MySQL, PostgreSQL, MongoDB, and other connectors.
- Bot Gateway integrations for Feishu/Lark, DingTalk, and other collaboration platforms.
- Progressive engineering plan design grounded in repository context.
- SQLite platform storage with tenant isolation, permissions, and auditability.

## 离线包 / Offline Package

本 Release 附带经过空数据启动验收的 macOS Intel (`x86_64`) 离线包，包含 WebUI、后端、本地多语言 Embedding 模型、ONNX Runtime、安装文档及升级脚本。

This release includes a clean-start verified macOS Intel (`x86_64`) offline package containing the WebUI, backend, local multilingual embedding model, ONNX Runtime, installation documentation, and upgrade scripts.

下载后先验证 SHA-256：

Verify SHA-256 before extraction:

```bash
shasum -a 256 -c aos-offline-0.1.0-darwin-x86_64.tar.gz.sha256
tar -xzf aos-offline-0.1.0-darwin-x86_64.tar.gz
cd aos-offline-0.1.0-darwin-x86_64
./scripts/setup-environment.sh --check
./scripts/aos-start.sh
```

完整安装、配置和升级说明请参阅仓库中的 `docs/INSTALL.md` 与 `docs/OPEN_SOURCE_DEPLOYMENT.zh-CN.md`。

See `docs/INSTALL.md` and `docs/OPEN_SOURCE_DEPLOYMENT.zh-CN.md` for complete installation, configuration, and upgrade instructions.
