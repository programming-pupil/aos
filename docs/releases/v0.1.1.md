# AOS v0.1.1

此版本将 AOS 离线发行扩展到五个桌面与服务器平台，并保留 v0.1.0 的全部能力和修复。

This release expands AOS offline distribution to five desktop and server platforms while retaining all v0.1.0 capabilities and fixes.

## 多平台离线包 / Multi-platform Offline Packages

- Linux x86_64
- Linux ARM64 (`aarch64`)
- macOS Intel (`x86_64`)
- macOS Apple Silicon (`arm64`)
- Windows x86_64

每个包均由对应架构的 GitHub 托管 Runner 原生构建，而非交叉编译。发布前会验证固定本地 Embedding 模型、ONNX Runtime、包内完整性清单、空数据库启动、Setup API 和 WebUI 路由。

Every package is built natively on a matching GitHub-hosted runner rather than cross-compiled. Before publication, the workflow verifies the pinned local embedding model, ONNX Runtime, the package integrity manifest, clean-database startup, the Setup API, and WebUI routes.

## 下载与校验 / Download And Verify

下载适合当前系统的压缩包以及同名的 `.sha256` 文件，然后验证：

Download the archive for your system together with its matching `.sha256` file, then verify it:

```bash
shasum -a 256 -c aos-offline-0.1.1-<os>-<arch>.tar.gz.sha256
```

Windows PowerShell：

Windows PowerShell:

```powershell
$Expected = ((Get-Content .\aos-offline-0.1.1-windows-x86_64.zip.sha256 -Raw) -split '\s+')[0]
$Actual = (Get-FileHash .\aos-offline-0.1.1-windows-x86_64.zip -Algorithm SHA256).Hash.ToLowerInvariant()
if ($Actual -ne $Expected) { throw 'Checksum mismatch' }
```

See `docs/INSTALL.md` and `docs/OPEN_SOURCE_DEPLOYMENT.zh-CN.md` for installation, first-run configuration, and lossless upgrade instructions.
